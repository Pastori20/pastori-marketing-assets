# Assets de redes

Imagenes de las piezas publicadas en las cuentas de Instagram de los SaaS.

El repo es **publico a proposito**: la API de Instagram no acepta archivos, descarga la imagen desde una URL. Aca no hay nada sensible, son las mismas piezas que se ven en el feed.

Estructura: una carpeta por marca, un archivo por pieza, nombrado con el id del posteo del calendario.
